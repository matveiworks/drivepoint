# DRIVEPOINT

Premium landing page for a fictional car-service brand (DRIVEPOINT) in Kyiv, Ukraine. Built as a single self-contained `index.html` — no build step, no dependencies.

**[View live via GitHub Pages](https://matveiworks.github.io/drivepoint/)** *(enable Pages → Settings → Pages → Deploy from branch `main` / root)*

## Stack

Plain HTML, CSS and vanilla JS. Fonts loaded from Google Fonts (Syne, Manrope, JetBrains Mono). No frameworks, no build tools — open `index.html` directly in a browser.

## Content

All copy is in Ukrainian. Sections: hero, quick booking form, services, why DRIVEPOINT, about, brands, before/after cases, process, reviews, pricing, lead-capture block, contacts, footer. Mobile includes a sticky booking CTA and a full-screen nav menu.
